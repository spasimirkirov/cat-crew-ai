# Commits

- One conventional sentence: `fix`, `add`, `update` — why, not a file dump.
- Stage only the files that belong to the change.
- The Git side panel can generate a message with the session brain (`AI message`).
- `git_commit` stages optional paths then commits. Empty message is an error.
- Do not force-push. Do not skip hooks.
