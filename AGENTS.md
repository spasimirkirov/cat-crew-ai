# Jinx AI

This is Jinx’s own repo. Prefer small patches over rewrites.

- **Product:** local AI agents that code and run autonomous tasks, plus an Assistant toolset (web, images, voice). Home → Members / Teams / Projects. Not a “companion” app.
- **Full picture:** `docs/JINX.md` (Big picture table + Tools + Agent harness). Keep that file current when you ship product surface.
- UI, logs, comments, README, and chat stay in English.
- Agent tools may edit this tree and any session workspace folders, then `restart_jinx`.
- Layout: custom titlebar + activity bar. **Home** first (Projects + Teams). **Members** is the bot catalog. Opening a project enters **Project Explorer** (Everyone + 1:1 chats). Computer (Files / Terminal / Git / DB) is takeover, not the landing screen. Overlay is a cyan/pink particle body. Icons are Font Awesome. Compact on/off chrome is an icon button: green when on, red slashed glyph when off — never a switch in the toolbar. Voice: start a call from the phone button; leave the call to hang up. No Hey Jinx wake word.
- Brains: Jinx-owned llama-server + GGUF folder (`C:\Jinx-AI\models`) by default. **AI Models → General** picks the model per role (Chat, Coding, Memory, Images). Local GGUFs and cloud hosts with a key show in the selector. Coding and Memory can follow Chat. Settings → API Access holds optional search keys (Brave) and a Hugging Face token for gated GGUFs. Settings → Connectors holds optional GitHub / Linear / Notion / Slack / MCP tokens (deferred tool schemas). Settings → Skills lists playbooks. Chat keys (DeepSeek, Google Gemini, Groq) live on **AI Models → Cloud API**. A key + enable toggle unlocks that host. **Local** launches llama-server on `127.0.0.1:8787` (default context 32768). **Hugging Face Hub** searches GGUF families, then a quant (+ mmproj) that fits ~70% VRAM. Titlebar download flyout + **Downloads** page for the pull queue. Per session. Switching mid-turn applies on the next model round. Command timeout, optional tool-round cap (0 = unlimited; Stop ends the turn), and optional tool approvals: Settings → General (not `.env`).
- Search: DuckDuckGo via `ddgs` (no Docker). Optional SearXNG URL or Brave key, then html fallbacks. Images: hidden local ComfyUI on a separate process (`generate_image`, `comfy_run_workflow`) — do not unload the chat LLM; do not open Comfy Desktop. Existing photos: `image_search`.
- Life: heartbeat journal (`data/life/`), evening idle wrap-up, then sleep. Settings → General → Life.
- Sessions / workspace: a **project computer** is `Project.folders` in the catalog (New project → Computer, or Files later). Everyone + 1:1 share it. New chat with no project starts with empty Files; folder picker opens at `C:\` when empty — never default the app install/source tree as the project. No folder → tools use `data/scratch/<session-id>/`. Harness TODO + activity live in that scratch (delete session removes it). Attaching a project that already has `.gitignore` appends `.jinx-ai/` if missing; never mkdir `.jinx-ai` or create a new `.gitignore`. Skills: `jinx_ai/skills/`, optional `C:\Jinx-AI\skills/`, optional existing `<ws>/.jinx-ai/skills/`. `AGENTS.md` / `SYSTEM.md` load only from attached folders. Product workflow: Home → Members / Teams / Projects → Project Explorer. Catalog in `data/platform/registry.json`. Spec: `docs/JINX.md`. New project Kickoff is the user’s first message to Chief (Everyone), not a generated brief. Everyone bubbles are **Chief of Staff**; 1:1 bubbles are the bot’s name. Bots share the project folder + kickoff/state + those docs. Teammate dossiers: `list_teams` → `list_members` → `get_member` (or `list_roster` for every card). 1:1 chats are not a group dump. Arcane is the official built-in team (`python scripts/init_arcane_team.py`).
- Developer coding: tools first, small patches, `search_files` is not Python-only, fetch official docs, `read_skill coding-companion` for long scaffolds. Use `update_todo` for the harness checklist — do not rewrite it with `write_file`. Prefer `run_subagent` / `run_code_mode` when they keep context cheaper. If a capped turn runs out of tool rounds, continue on the next message. 0 rounds is unlimited. Never paste tool-call JSON into the chat. Shell is first-class: `npm`, `npx create-react-app`, `npm start` / `node server.js` (Terminal tab), composer, tests. Pass `cwd`, not a lone `cd`. Stop kills the current command. Composer: Enter queues while she works; Ctrl+Enter / bolt steers now.
- Session tree: jump to an earlier turn; branches stay in the JSON. Slash templates: `/review`, `/commit`. Chat toolbar list = activity timeline; download = export. In-chat activity is a **Worked for Xm Ys** line with a chevron, not a throwaway card. Everyone = **Chief of Staff**.
- Do not add a Node/pi.dev runtime. Steal harness ideas into Python instead (`docs/TRUEFORGE_STEAL_BACKLOG.md`).
- After a code change, `python -m compileall -q jinx_ai` then `python -m pytest -q` is a reasonable smoke check.
- Self-knowledge: every chat turn loads `docs/JINX.md` plus the skill index. Playbooks stay on `read_skill`.
